AirLink — TEG Platform

A robust communication platform for both local WLAN and the open internet. Not a chat app — a full system: WebSocket messaging across 7+ channels, WebRTC peer video calling, in-chat voice recording, chunked resumable file transfers, QR-code device pairing, a wireless sensor network manager, and a zero-config UDP peer discovery engine.

  • WebRTC video + voice notes via Web Audio API
  • Resumable chunked file uploads with progress tracking
  • QR code instant device pairing

  • Cross-network relay tunnelling

About

I’m Tendai Ernest — a systems builder creating technology that works in the real world.

I’m the founder of GAVIH Integrated Systems, where I design, build, and ship real engineering projects — from connected devices and embedded systems to intelligent software and interactive applications.

My work spans the full stack: low-level C firmware running on hardware, Python and FastAPI backends, real-time communication with WebRTC and WebSockets, computer vision, IoT, networking, and the interfaces people actually use.

What drives me is not technology for its own sake. It’s the moment an idea becomes a working system — when devices connect, software responds, data moves, and something that once existed only as an idea becomes real.

I’m continuously deepening my expertise in AI integration, distributed systems, and developer-focused tools, while building practical technology that solves meaningful problems.

I build systems from the hardware up — and I’m always looking for the next problem worth solving.
