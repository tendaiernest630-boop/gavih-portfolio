01 Flagship Project
Real-Time Communication Platform · Sole Developer

AirLink — TEG Platform

The problem: devices on the same network had no easy way to communicate, share files, or stream video without configuring servers, port-forwarding, or relying on third-party services. So I built one from scratch.

AirLink TEG is a self-hosted communication platform that works on your local network or over the internet — handling real-time messaging, peer-to-peer video calls, voice recording, resumable file transfers, IoT sensor telemetry, and automatic device discovery with no manual network configuration required.

  • Sub-millisecond LAN messaging over persistent WebSocket connections
  • Browser-based peer-to-peer video & voice via WebRTC
  • Resumable chunked file uploads with real-time progress tracking
  • QR code device pairing — scan and connect instantly
  • UDP broadcast peer discovery — devices find each other automatically
  • Live WSN sensor telemetry from physical Arduino hardware
  • Cross-network relay tunnelling for internet-wide access

Zero-Config Peer Discovery

On a local network, devices don't know each other's IP addresses unless someone tells them. I built a UDP broadcast beacon system that removes that problem entirely — devices announce themselves and register with any listening peer automatically.

  • UDP broadcast beaconing on port 50555
  • Automatic peer registration on first contact
  • Cross-platform, zero configuration required
  • Core discovery layer inside AirLink TEG
PythonUDPSockets

GAVI — Forex Signal & Risk Engine

A full-stack automated Forex analysis system with a deterministic Risk Engine built as an independent safety layer. The engine processes market data, generates signals, and enforces configurable circuit breakers — completely separate from the signal logic so neither can override the other.

  • Independent Risk Engine: daily loss limits, consecutive loss circuit breakers, position caps
  • Three operating modes: Manual, Assisted, and Autonomous
  • Pre-trade risk evaluation before any position is considered
  • Conversational analysis engine explains every decision in plain language
  • Emergency pause & close-all controls for capital protection
  • Full dashboard: trade history, telemetry, settings

About

I build systems
from the idea
to the thing that works.

I'm Tendai Ernest — founder of GAVIH Integrated Systems and the person who builds what needs to be built.

My work covers the full distance from hardware to software: C firmware running on microcontrollers, Python backends handling real-time connections, computer vision pipelines, IoT sensor networks, automated systems, and the interfaces people actually interact with.

What drives me is a specific moment — the moment an idea becomes a working system. When a device connects to the network for the first time, when the detection model draws its first accurate bounding box, when a signal engine fires and the logic holds. That moment is what I'm building toward every time.

I don't start with a preferred technology and fit the problem to it. I start with the problem, figure out what it actually requires, and build accordingly. Sometimes that means writing firmware in C. Sometimes it means designing a communication protocol from scratch. Sometimes it means building an independent risk engine so a system can't hurt the person using it.

If you have a technical problem you're not sure how to approach — that's exactly the kind of problem I want to talk about.
